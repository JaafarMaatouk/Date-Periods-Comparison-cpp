# C++ Periods Overlap Checker

A console-based C++ application designed to determine whether two specific date periods overlap. This project focuses on advanced date comparison logic using structs and enums.

## 🎮 How it Works
1. The program prompts the user to enter Period 1 (Start Date and End Date).
2. Then, it prompts the user to enter Period 2 (Start Date and End Date).
3. It accurately compares the dates and prints whether the two periods overlap or not.

## 🛠️ Technical Details
- Uses nested structs to represent a stPeriod containing stDate (Start Date & End Date).
- Implements precise date comparison functions (Before, After, Equal).
- Utilizes enum for clear and readable date comparison results.
- Employs logical operators to detect overlaps between two timeframes.

## 🚀 How to Run
1. Clone this repository or download it as a ZIP file.
2. Open the .sln file in Visual Studio.
3. Press F5 or Ctrl + F5 to build and run the program.
4. Enter the start and end dates for both periods to see the result.
